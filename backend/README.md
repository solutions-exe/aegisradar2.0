# AEGIS RADAR - Backend
Aegis Radar Contains A Highly Responsive Backend Server Which Can Handle large Amount Of Transactions per second, Relying On An Efficiently Designed ML ModelS(XGBOOST & Isolation Forest) Trained On The Best Fraud Detection Datasets With A Signal Oriented Approach That Allows Our Aegis to Detect The Fraud In Real-Time Before It Costs Our Users Thier Time and Money. With Easy And Straight Forward API Integeration Procces You would Be Suprised With How Quick You Can Link Your Bussines to Our Service And Enjoy Your Everyday Volume With Almost ZERO Fraud.

## Runnung
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt

### Runnung 
python run.py

#### Key Directories
app/routers/ → API endpoints
app/models/ → Database models
app/detection/ → ML ensemble logic
scripts/ → Testing & seeding
